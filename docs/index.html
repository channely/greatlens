WHAT IT DOES

从文字到画面，一条链路打通

围绕创作的实际动作设计，而不是堆砌功能清单。

01

语义节点剧本

场景、动作、对白、转场、字幕按语义分段编辑；自动派生角色、地点与场景，改剧本时实体跟着更新。

02

定点 AI 改写

可精确指定光标、选中文字、节点或区间作为上下文，改写结果原位替换；知识库按需检索，不整库塞给模型。

03

实体与生产管理

选角表、关系图谱、地点道具与连续性审计；"声明但从未同场"的关系自动标出，供结构诊断参考。

04

多轨时间轴

画面 / 声音 / 字幕 / 节拍四轨编排，秒刻度与播放头、镜头拖动改时长、目标时长与超时提示。

05

节拍与结构

Save the Cat 15 节拍模板与强度曲线，对照大纲检查因果起伏，一眼看出节奏平淡的段落。

06

图像 / 视频 / 导出

百炼文生图与文生视频，素材本地持久化；FDX / PDF / DOCX / TXT 工业格式导出与 Fountain 导入。

07

交付前检查

导出前集中核对实体登记、时长超限与镜头完整性；写作时新增未登记的角色 / 地点即时提示。

08

为重度使用设计

项目级撤销 / 重做（60 步）、命令面板（⌘/Ctrl+K）、播放头预览，减少来回切换。

THE PIPELINE

一条创作动线

灵感 → 大纲一句话 brief 生成分集结构
大纲 → 剧本按场展开为语义节点
剧本 → 分镜拆镜头，挂参考图作视觉约束
分镜 → 画面时间轴编排与图像 / 视频生成
RUN LOCALLY

三步跑起来

需要 Node.js 22.23.4+。首次在「设置」页填入自己的百炼 API Key 即可开始创作。

文本模型阿里百炼 qwen4-max（含 thinking）
图像模型qwen-image-3.0（按张计费）
视频模型wan3.0-video（按秒计费，最长 30 秒）
视频分辨率默认 480P，可选 720P / 1080P
访问地址http://127.0.0.1:8787
