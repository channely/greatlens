# GreatLens

自研的 AI 原生剧本 / 短片创作工作台。功能与交互逻辑参考公开可观察的产品形态，代码全部自研重写，不复制原产品的专有源码、品牌标识或商标。单人自用，数据全部留在本地。

## 启动

需要 Node.js 22.23.4+（本机用 nvm v24.22.3）：

```bash
cd /Users/cc/code/GreatLens
nvm use 24.22.3
npm install
npm run build     # 首次或改动前端后执行
npm start
```

打开 http://127.0.0.1:8787

开发模式（前后端热更新）：

```bash
npm run dev
# 前端 http://127.0.0.1:5173，API http://127.0.0.1:8787
```

## 当前模型配置：阿里百炼 qwen4-max

首次启动后请在「设置」页填入自己的百炼 API Key（前端只显示末四位掩码）：

| 项 | 默认值 |
|---|---|
| Base URL | `https://dashscope.aliyuncs.com/compatible-mode/v1`（专用工作区请填你的专属域名） |
| API Key | 首次为空，需自行填写（本地文件，前端不可见明文） |
| 文本模型 | `qwen4-max` |
| 思考模式 | 开启（`enable_thinking`，思考链单独展示并计入输出 Token） |
| 图像模型 | `qwen-image-3.0`（默认，同步接口，出图即下载到本地） |
| 视频模型 | `wan3.0-video`（默认，异步任务，最长 30 秒，自动轮询并下载） |
| 视频默认分辨率 | `480P`（可选 720P / 1080P） |
| 媒体 Base URL | `https://dashscope.aliyuncs.com/api/v1` |

模型目录与计费口径以 `server/models.js` 为单一事实来源，`GET /api/models` 供前端下拉与价格展示；设置页改动会即时反映到素材工作台的估算费用

在「设置」页可改任意项、点「测试连接」验证。所有模型请求经后端代理，Key 不进前端。若使用百炼专用工作区端点，Base URL 与媒体 Base URL 都要改成工作区域名。

**安全提醒**：你此前在对话中贴过完整 API Key，建议用完一段时间后到百炼控制台轮换一次；新 Key 只需在设置页替换。`.gitignore` 已排除 `data/`，避免误提交。

## 功能

**Script 剧本工作台**
- 语义节点编辑器：场景 / 动作 / 角色 / 对白 / 括号 / 转场 / 字幕 / 批注；Shift 点选节点区间、右键菜单、拖拽排序
- 从剧本自动派生场景、角色、地点；大纲、世界观、角色档案、分镜表
- **AI 定点改写**：读取范围含「节点 / 选中区间」；改写可原位替换选中节点，不再只能追加末尾
- **落点四要素**：请求携带 target / intention / constraints / authority，附项目级上下文（剧集清单、世界观、知识库**仅索引**、实体清单）；全稿读取上限 800 节点
- **Advisor 顾问视角**：6 种方法论 lens（剧本医生 / 结构 / 对白 / 制片 / 短剧节奏 / 视听语言），单顾问切换 AI 诊断视角
- AI 助手：显式读取范围 + 五种模式；**思考过程可折叠展示**；一键按行采纳为语义节点
- **交付导出**：FDX / PDF / DOCX / TXT（Hollywood / Asian 惯例，多集合并，中文 PDF）；另保留 Fountain / Markdown / JSON
- **FDX / Fountain 导入**：项目页「导入 FDX / Fountain」，可新建项目或合并到现有项目，自动识别场景/动作/角色/对白/括号/转场
- **字级选区改写**：拖动选中节点内任意文字，只让 AI 改这一段并原位替换
- **创意资料导入**：项目页「导入资料」支持 DOCX / PDF / MD / TXT，解析后加入知识库或据此新建项目

**生产管理层**
- 选角表、SVG 关系图谱（自动标出"声明但从未同场"的关系与零连接角色）
- 地点 / 道具视图 + 连续性审计；地点画布 / 分组 / 关系图三视图
- 知识库：index → search → read，AI 只拿索引、按需读取正文；worldview 需显式授权写入
- 深 / 浅主题切换（自动记忆、多标签同步）

**节拍与时间轴**
- Beats 节拍板：Save the Cat 15 节拍模板、强度曲线、AI 生成 / 细化节拍、大纲对照
- 多轨时间轴：画面 / 声音 / 字幕 / 节拍四轨、秒刻度与播放头、镜头时长拖动、目标时长与超时提示
- 播放头预览：点击镜头或标尺移动播放头，预览当前镜头的参考图 / 文字摘要与视觉约束
- 分镜参考图：每个镜头挂本地素材图 + 视觉约束备注，AI 分镜保持一致

**交付与效率**
- 交付前检查：导出弹窗聚合实体登记、时长超限、镜头 / 节拍完整性，分「需核对 / 可优化」提示
- 写作现场提示：剧本里新增未登记的角色 / 地点即时提示，可一键跳到生产视图登记
- 撤销 / 重做：`⌘/Ctrl+Z`、`⇧⌘Z`（或 `Ctrl+Y`），最多 60 步；输入框内仍用文本级撤销
- 命令面板：`⌘/Ctrl+K` 唤出，覆盖导航、编辑、视图与文件操作

**Cinema 短片工作台**
- 五阶段流水线：场景 → 表演 → 文字分镜 → 分镜图 → 成片
- 单条 Reel 最长 30 秒（时长可编辑，顶栏 / 表演 / 成片阶段据此显示），支持末帧接续 / 自然过渡
- **成片阶段可直接生成**：自动组装场景 + 表演 + 镜头 + 负面提示为 prompt，选分辨率（480P/720P/1080P）后一键用 `wan3.0-video` 生成整条视频；派发前显示估算费用，生成多版本可对比选用并自动回填，也可手填外部 URL 兜底
- 内置《海风与橘子 Cinema》示例：30 秒装入 1 个 Reel、7 个镜头（0–30s）

**素材工作台**（百炼图像 / 视频）
- 图像：正向/负向提示词、尺寸、模型、数量、参考图 URL（图生图）；同步出图
- 视频：文生视频 / 图生视频（首帧 URL）、输出时长（1–30 秒）、输入视频时长、分辨率（480P/720P/1080P）、watermarks
- 实时估算费用：按所选分辨率的每秒单价 ×（输出时长 + 输入视频时长）
- 任务自动轮询；网络抖动不误判失败（自动退避重试），刷新页面后未完成任务自动恢复轮询
- **生成的图片/视频立即下载到 `data/assets/`**，不依赖百炼 24 小时临时 URL
- 素材库可复制本地 / 远端 URL、删除

**流程对齐补充**
- idea-first 开局：项目页「从创意开始」按 brief → 标题 → 大纲 → 节拍 → 角色 → 地点 → 开场 → 复核建项，创建后逐视图复核
- 封面 / 剧本双视图：`project.cover` 独立保存标题页信息，不污染语义节点；Script Doctor 固定「诊断 → 处方 → 选择 → 采纳」，结构化动作按稳定节点 ID 写入，目标变化即拒绝
- 项目设置 Project / Format / AI 三 tab；导出弹窗的剧本惯例与项目设置同源，不维护第二份状态
- 版本历史：自动 / 命名 / 恢复前快照分层保存，保存带 `If-Match`，旧标签页不能覆盖新状态；恢复前自动备份
- 场景 table / canvas、分镜 panel / table / canvas 三视图；Space 只展示当前项目的资产画布与任务列表
- 本地上传与实体素材槽：角色 / 地点 / 道具 / 场景 / 镜头可绑定图片或音频；上下文生成从真实项目字段组装 prompt 并自动回填首图
- 声音视图：导演圆桌与剧本围读同步合成；超长要求缩小范围，成本按可计费 Token 记账，接口未返回 Token 时标「未知」

**REA 复审后补齐的非协作能力**
- 任务自愈与冲正：查询/提交对瞬时错误退避重试；远端失败时后端自动重提一次（前端 taskId 不变），失败即冲销已记费用；素材卡可手动「冲销计费」，净额在用量页抵扣
- 作者口味记忆：对 AI 回复点「👍 喜欢 / 👎 弃用」或写显式规则，偏好按项目沉淀并注入后续创作；「口味」面板可查看、删除、关闭（优先级低于本次要求）
- 修订说明与 Option 备选：创作助手「修订」入口对节拍/节点生成 Option 1/2/3，选定后按稳定 ID 与 revision 安全写入；修订说明只做批注不改原文
- 新建项目起始模板：Script 可选空白剧本 / 三幕结构 / 角色优先，预置可编辑大纲、节拍或角色骨架
- 电影海报：封面视图「生成电影海报」按片名/Logline/世界观/人物场景组装专用 Prompt，回填 `project.posterImage`

## 用量与计费

「用量」页展示：总调用次数、总 Token（输入/输出/思考链分列）、估算费用、近 30 天柱状图、按模型明细、最近调用明细。

- 文本：qwen4-max **输入 ¥10/百万 Token、输出 ¥30/百万 Token**（思维链计入输出，华北2北京）；Token 数来自百炼真实 `usage`，**精确**
- 音频（qwen-audio-3.1-tts-next，**北京**）：输入 ¥6 / 输出 ¥12 每百万 Token；圆桌 ≤240 秒、其他 ≤120 秒，prompt ≤3000 字符。只有接口返回可计费 Token 才记精确成本，否则标「未知」
- 图像（qwen-image-3.0）**按张计费**：生成 ¥0.18/张 + 输入图 ¥0.02/张（1K 与 2K 同价）
- 视频（wan3.0-video）**按秒计费，单价由输出分辨率决定**：480P ¥0.3/秒、720P ¥0.6/秒、1080P ¥1.2/秒（控制台标价，当前限时 7 折 → 默认折扣系数 0.7，即折后 ¥0.21/0.42/0.84 每秒）。**单条最长 30 秒**；输入视频与输出视频均按秒计入，单价取输出分辨率档
- 以上图像 / 视频为**本地估算**：单价与折扣均可在「设置 → 计费单价」修改（`data/settings.json` 的 `imageGenPrice` / `imageInputPrice` / `videoPrice480P` / `videoPrice720P` / `videoPrice1080P` / `videoDiscount`），实际以阿里云账单为准
- 全部记录只存本地 `data/db.json` 的 `usage` 数组；最近调用明细悬停费用可看计费口径
- 冲正：任务失败或手动冲销会写入一条负成本 `kind:refund` 记录，按 `refundKey` 幂等；净费用自动抵扣，但不增加调用次数。可用 `GET /api/usage/refunds` 查看全部冲正

## 异地协作（公司与家里两台电脑）

两种模式，按场景选：

**A. 共享后端（推荐，实时看到同一份数据）**
1. 在一台常开的电脑上启动服务，用内网穿透暴露端口，例如 Cloudflare Tunnel：
   ```bash
   cloudflared tunnel --url http://127.0.0.1:8787
   ```
2. 另一台电脑在「设置 → 异地协作 → 远程后端地址」填入 `https://xxxx.trycloudflare.com/api`（留空则用本机）
3. 前端所有请求自动走该地址，两端操作同一份 `data/db.json`

> 注意：A 模式下密钥在常开那台机器上。穿透地址不要公开分享。

**B. Git 快照同步（离线交替使用，非实时）**
1. 建一个私有 Git 仓库（GitHub / Gitee / 自建均可），生成访问令牌
2. 两端在「同步」页填仓库 HTTPS 地址 + 令牌 + 设备名（如「公司Mac」「家里Mac」）
3. 离开一台电脑前点「推送本地更改」，到另一台点「拉取远端更改」
4. 拉取前自动备份本地 `db.json` 到 `data/backups/`；**API Key 与同步令牌不会进入远端**
5. 冲突策略：同名快照后写覆盖先写（自用双机场景足够；这是快照同步，不是实时协同编辑）

## 数据与安全

- `data/db.json`：项目、剧集、剧本节点、实体、任务、用量、素材索引
- `data/settings.json`：模型配置与密钥（**明文存本地，勿外传**）
- `data/assets/`：生成的图片/视频实体文件
- `data/backups/`：拉取前的自动备份
- `data/.sync/`：Git 同步工作目录
- 以上目录均在 `.gitignore` 中

## 与 laper 的能力对齐（2026-11-20 深度迭代后）

按 laper 官方文档逐项对齐个人使用所需能力，保留我方更强项：

- **有意保留的超集**：Cinema 单条最长 30 秒（laper 固定 15 秒）、默认 480P 可选 720/1080、按秒折扣计费
- **有意对齐的差异**：Script 与 Cinema 是 peer 文档类型（不合并）；idea-first 不套起始模板；仅支持 FDX 导入、不做 Fountain 导入/导出；排除团队协作、角色权限、社区 Remix
- **Script→Cinema**：官方对等文档，提供一次性显式转换（场景→Reel、角色/道具复制），源项目不变，不做往返自动同步
- **任务分流**：素材工作台为项目级自由生成，Cinema 成片为 reel 绑定任务；冲正记录可在「用量」查看
- **防虚假功能**：`tests/noFakeUI.test.mjs` 静态拦截装饰性假入口与失效 api 路由；所有可见控件均有真实数据副作用
