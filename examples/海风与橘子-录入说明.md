## 三、剧本（事实来源）

`episodes[0].nodes` 共 13 个语义节点，按叙事顺序：

- `scene` 场景标题：`EXT. 近海码头 - 黄昏`
- `action` 动作：每镜的可见行为（可拍摄的描述）
- `character` 角色提示：沈屿、沈岚（让角色派生正确识别两人）
- `dialogue` 台词：`走了，下次海上见。`
- `subtitle` 字幕：`有些告别，是把梦想丢给你。`
- `comment` 批注：全片音效设计（批注不进导出）

## 四、分镜与时间轴

`episodes[0].shots` 6 个镜头，字段映射：

| 原始分镜项 | GreatLens 字段 |
|---|---|
| 画面 Prompt | `visual` |
| 镜头运动 | `motion` |
| 动作 | 已拆入 `nodes` 的 action（分镜这里不重复） |
| 音效 | `audio` |
| 景别（大全景/中景/特写…） | `shotSize` |
| 时长（0–4s / 4–8s…） | `duration`（4/4/4/5/7/6s，合计 30s） |
| 机位 | `camera`（摇臂俯拍/横移/跟拍/手持/拉远/固定） |

时间轴页会按 `duration` 排四轨（画面/声音/字幕/节拍），并画出 30s 目标线。
播放头点某个镜头，会预览它的画面描述；后续在「素材」页生成图并挂到 `refImage`，预览会直接显示画面。

## 五、结构辅助

- `outline[]`：6 条结构概括（大纲页）
- `beats[]`：6 拍（建立→摘帽→抛橘→告别→驶离→目送），带 tension 强度，节拍板可看曲线
- `settings.exportConvention = asian`：导出默认用亚洲剧本惯例

## 六、接下来你可以做什么

1. 打开项目，到「分镜」或「时间轴」看 6 镜排布
2. 到「素材」页用画面 Prompt 生成参考图，再在分镜里挂到对应镜头的参考图槽位
3. 用创作助手做定点改写：选中某段文字，让它按世界观约束细化画面
4. 导出前打开「交付导出」，看交付前检查是否有需要收口的项（当前只有"未挂参考图"一条可优化提示）
